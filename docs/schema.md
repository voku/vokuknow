# Schema

`vokuknow` reads `.vokuknow/schema/`:

- `AGENTS.md`
- `entity_types.yaml`
- `relation_types.yaml`
- `claim_policies.yaml`
- `source_policies.yaml`
- `privacy_policies.yaml`
- `prompt_profiles.yaml`

Validation enforces required files, required policy fields, and required AGENTS guidance terms.
